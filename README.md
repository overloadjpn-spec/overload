## ✏️ メンバー情報の更新方法

`index.html` の中にある `memberData` という一覧を書き換えると、メンバーカードの表示内容が変わります。

```js
{name:"名前", kana:"よみがな", role:"自由記入欄", color:"#カラーコード"},
```

- `role` はキャッチフレーズやポジションなど、好きな内容に変更できます
- `color` はアバターの背景色です（16進数カラーコードで指定）
- 新しいメンバーを追加したいときは、この形式のまま行を増やしてください
